## 3. Compare and contrast Agile and Waterfall methodologies. What are the main advantages and disadvantages of each?
1) Agile - It is quick to repond to changes and regular customer feedback. The disadvantage is that there is a lack of predictability in which can affect the outcome of the project.
2) Waterfal - It has clear structure and documentation, one step finishes before moving to the next. The disadvantage is that it is inflexible, you can go back and make changes without disrupting the whole project.
